# Employee Performance Prediction

## 1. Project Overview

INX Future Inc. wants to understand the factors associated with employee performance and use data to support better HR decisions. This project uses employee information to analyse performance ratings and develop a machine learning model that predicts employee performance.

## 2. Business Problem

Understanding employee performance can help an organization identify patterns in employee satisfaction, work experience, job roles, and other workplace factors. Analysing these patterns may help HR teams make more informed decisions.

The main challenge is to identify the factors most strongly associated with performance ratings and evaluate how accurately machine learning models can predict those ratings.

## 3. Project Objectives

The objectives of this project are:

- Analyse employee data to understand performance ratings.
- Identify patterns and relationships between employee characteristics and performance.
- Prepare the dataset for machine learning.
- Train and compare different classification algorithms.
- Evaluate model performance using suitable classification metrics.
- Identify the features the final model relies on most.
- Save the selected model for future predictions.
- Provide recommendations based on the analysis.

## 4. Dataset Description

The project uses employee data provided for the INX Future Inc. employee performance case study.

The dataset contains information about employee demographics, education, department, job role, work experience, job satisfaction, workplace environment, salary hikes, and performance ratings.

The target variable is `PerformanceRating`, which represents the employee's performance category.

## 5. Scope of the Project

The project covers data cleaning, exploratory data analysis, feature engineering, data preprocessing, model training, model evaluation, hyperparameter tuning, feature importance analysis, and prediction using the saved model.

Four classification algorithms are compared:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## 6. Expected Outcome

The expected outcome is a trained classification model that can predict employee performance ratings from the available employee information.

The analysis should also identify important patterns in the dataset and provide recommendations for HR decision-making.

Model predictions should support human judgement rather than replace it, especially when decisions could affect employees or job applicants.
