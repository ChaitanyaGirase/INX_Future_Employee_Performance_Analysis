
# Project References

This project is based on the employee performance dataset and project instructions provided for the INX Future Inc. Employee Performance Analysis project.

## 1. Dataset Source

- **Dataset:** INX Future Inc. Employee Performance Dataset
- **Source:** Provided as part of the IABAC Certified Data Scientist project.
- **Records:** 1,200 employees
- **Features:** 28 columns
